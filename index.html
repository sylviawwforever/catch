每日热点 · 舆情事件 · 选题雷达

CATCH 每天自动巡检微博、抖音、小红书、X、知乎、新闻等公开榜单， 抓取真实条目并完成跨平台共振聚类，输出可写、可查、可引用的舆情事件档案。

每个事件附：事件概括梳理、每 6 小时更新走势、每日词云、情感倾向分布与真实高赞热评样本， 全部条目保留原始链接，供论文附录与信源复核使用。

01 / Cross-Platform Board

跨平台
热榜总览

同一时点抓取各平台公开热榜，按各平台原榜序位综合排序——因为微博的搜索热度、 知乎的讨论热度与抖音的点赞量口径不同，绝对值不可直接比较，只作展示，不参与排序。 左侧可按平台切换。

02 / Trending Now

热点

正在流通的话题与梗，含平台归属、共振词与可选采写角度。

03 / Internet Slang

网络流行语

不引用任何年度榜单。以近 7 天各平台公开热榜逐日归档为语料（微博 / 抖音 / 知乎 / 百度 / 今日头条）， 枚举标题中的中文片段，保留同时满足「跨 ≥2 天复现」「跨 ≥2 个不同句式或平台」 「非硬新闻语境」「与教学 / 挑战 / 转场 / 穿搭 / 治愈 / 翻唱等可复用句式共现」四条结构判据的词； 再由百度百科开放 API 逐词仲裁类别——判为网络流行语 / 网络用语的直接采纳并引用百科释义， 判为人物、机构、地名或普通词义的剔除，无词条的新词则依据其真实热榜语境归纳。 最终按近 7 天热榜实际出现次数排序。

04 / Public Opinion Events

舆情事件

只有当同一实义实体在两个及以上平台同时出现时，系统才将其判定为舆情事件， 并围绕它组装完整档案：概括梳理、每 6 小时走势、每日词云、情感倾向与热评样本。

键盘 ↑ / ↓ 可切换事件。

04 / Story Radar

选题雷达

评分 = 热度 ×0.30 + 争议度 ×0.28 + 跨平台共振 ×0.24 + 样本充分度 ×0.18。 争议度由消极与愤怒占比合成，样本充分度由热评条数折算。

每张卡片附可选角度与研究方法建议。

方法论
与数据源
